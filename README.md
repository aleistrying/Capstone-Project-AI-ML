# Summary:CineAssist

CineAssist is an AI-powered movie recommendation chatbot that helps users discover movies through natural language interaction.
Instead of browsing endless movie lists, users can describe what they want to watch using conversational prompts such as:

------> "I want a funny sci-fi movie like Guardians of the Galaxy"

The system analyzes user preferences including genre, mood, language, themes, favorite movies, and ratings to generate personalized movie recommendations with explanations.

---------------------------------------------------------------------------------------------------

# Project Goals 

The objective of CineAssist is to build an intelligent recommendation system that combines:

- Natural Language Processing (NLP)
- Content-Based Recommendation Systems
- Machine Learning
- Conversational AI
- Explainable Recommendations

The project is being developed as a capstone project for the AML-2403 AI and ML Lab course.

-----------------------------------------------------------------------------------------------------

# Features

1. Current MVP Features

- 🎥 Movie recommendation engine
- 💬 Chatbot-style interaction
- 🧾 Natural language preference extraction
- 🔍 TF-IDF + cosine similarity recommendations
- ⭐ Ranked recommendation results
- 📖 Recommendation explanations

2. Planned Features

- 🌎 Multilingual support
- 🤖 Semantic search using embeddings
- 🎭 Mood-based recommendations
- 📊 Recommendation evaluation metrics
- ☁️ Cloud deployment
- 👤 Optional face-recognition login (stretch goal)

# ---------------------------------------------------------------------------
# Deploy branch requirements — Streamlit Community Cloud.
#
# Deliberately slimmer than main's. The hosted container has ~1 GB of RAM and no
# persistent disk, so the ML translation stack is left out:
#
#   torch, torchvision, transformers, sentencepiece, datasets, evaluate, sacrebleu
#
# MarianMT alone downloads ~300 MB per language pair on first use, and a cold
# start would re-download it every time the container recycles. src/chatbot/
# chatbot_flow.py imports translation lazily and no-ops when it is unavailable,
# so the hosted app runs English-only instead of failing. Page 4 (Translation
# Quality) still loads — src/metrics/translation_quality.py imports torch inside
# its functions — but reports the ML scorer as unavailable.
#
# spacy is also dropped: it appears only in notebooks/lili/project.ipynb, never
# on the serving path.
#
# For the full multilingual experience, install main's requirements.txt locally.
# ---------------------------------------------------------------------------

pandas

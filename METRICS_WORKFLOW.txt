================================================================================
                            METRIC INTERPRETATION
================================================================================

PRECISION (How good are the recommendations?)
  Formula: (# of relevant movies we recommended) / (# of movies we recommended)

  Precision 0.800 = 80% of our recommendations were relevant
  ✓ Good range: > 0.70
  → If low: recommender is suggesting irrelevant movies

RECALL (How complete are the results?)
  Formula: (# of relevant movies we recommended) / (# of all relevant movies)

  Recall 0.600 = We found 60% of all relevant movies
  ✓ Good range: > 0.60
  → If low: recommender is missing many relevant movies

ACCURACY (Overall correctness)
  Formula: (Correct predictions) / (Total items in dataset)

  Accuracy 0.950 = 95% of all items were classified correctly
  ✓ Good range: > 0.70

F1 SCORE (Balanced performance)
  Formula: Harmonic mean of Precision and Recall

  F1 0.686 = Good balance between precision and recall
  ✓ Good range: > 0.60
  → Use this when you want both precision AND recall to be good

MRR (How early are relevant results?)
  Formula: 1 / (rank of first relevant movie found)

  MRR 1.000 = First relevant movie at rank 1 (perfect!)
  MRR 0.500 = First relevant movie at rank 2
  ✓ Good range: > 0.50
  → If low: relevant movies are appearing too late in ranking

================================================================================
                            TROUBLESHOOTING
================================================================================

❌ "ModuleNotFoundError: No module named 'recommender'"
   → Make sure you run from project root directory
   → Try: cd d:\ingepsicomaster\Projects\Capstone-Project-AI-ML

❌ "Could not find data/movies_final.csv"
   → Your data is in Databricks. Either:
     a) Run in Databricks notebook
     b) Export data: spark.read.table(...).toPandas().to_csv(...)

❌ "Could not load tfidf_vectorizer.pkl"
   → Make sure notebooks/03_Vectorization.ipynb has been run first
   → Check that models/ folder contains the pkl files

❌ "Test scenarios have empty relevant_movie_ids"
   → You forgot Step 2! Edit test_data.py with movieIds from Step 1

❌ "Recommender returned empty results"
   → Your query might be too specific
   → Or the tfidf_matrix might not be loaded properly
   → Check that tfidf_matrix.pkl exists in models/ folder
